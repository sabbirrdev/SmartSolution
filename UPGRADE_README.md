# Smart Solution — Enterprise Edition

This build uses the existing client-side Smart Solution architecture and upgrades the product shell to an enterprise workspace.

## Included
- Nilkhet Blue, Studio Dark, Minimal Paper themes
- Canvas mouse tracking toggle
- Enterprise navigation/header
- Animated glass/plate UI system
- AdSense publisher script: `ca-pub-6608561249557105`
- Existing client-side utility matrix and local auth/profile flows

## Run
```bash
npm install
npm run dev
```

## AdSense
The publisher script is installed globally in `app/layout.jsx`. Ad placement itself should be configured through your AdSense account/Auto ads or a specific ad-unit slot once approved.
