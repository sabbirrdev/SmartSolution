# Smart Solution — Bangladesh Digital Center OS

Production-ready client-side Next.js + Tailwind frontend.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Included

- Nilkhet Blue / Studio Dark / Minimal Paper themes
- Canvas particle cursor toggle
- LocalStorage authentication/profile state
- Mock Google login, registration and OTP reset
- Wallet and transaction UI
- Teletalk 300x300 / 300x80 formatter
- Ink Saver canvas engine
- Passport / Visa / NID cropper
- PNG / JPG / WebP converter
- Unicode → Bijoy client-side workflow
- Signature canvas
- Bangladesh legal document templates
- PC builder and compatibility engine
- Age / VAT / EMI calculators
- QR-style local generator, password generator and text analytics
- AI Studio with session-only API-key field and Demo Mode
- No backend required
